# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-01

### Added
- Initial release of DeepDetect AI
- Multi-modal deepfake detection (images, video, audio)
- Live camera HUD interface with face detection
- Real-time analysis using Google Gemini 1.5 Flash
- PDF export functionality for forensic reports
- Interactive metrics dashboard with Recharts visualization
- Session-based scan history (no database required)
- Responsive dark royal UI design
- Support for web forensics via Python microservice

### Technical
- React 18 + Vite for frontend
- Node.js + Express for backend API
- TypeScript for type safety
- Tailwind CSS for styling
- Framer Motion for animations
- face-api.js for facial detection
